# Fotos de portada de la base de pruebas

Solo para `npm run seed`: la primera foto (la portada) de cada coche de prueba es una foto real del
modelo; el resto siguen siendo imágenes de color. No son coches del cliente ni de su stock, y algunas
son de una generación más nueva que el año del coche de prueba.

Vienen de Wikimedia Commons, recortadas a 1200 × 900. Las licencias CC BY-SA piden citar al autor y la
licencia si se publican: aquí están. No se usan fuera del sistema de pruebas.
